# Huitzilin Aerospace — Hardware-in-the-Loop (HITL) Simulation System

This repository contains the **Hardware-in-the-Loop (HITL)** testing environment for the **Huitzilin Autonomous Drone Swarm Project**. It bridges bare-metal ESP32 FreeRTOS flight control firmware with ROS 2 Jazzy and Gazebo Sim via a high-speed UART bridge.
